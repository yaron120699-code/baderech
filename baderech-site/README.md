# בדרך. — דף נחיתה

דף נחיתה אישי לליווי ולהתפתחות אישית. עברית מלאה, RTL, ללא framework — HTML/CSS/JS פשוטים.

## מבנה הפרויקט

```
.
├── index.html          # המבנה והתוכן של הדף
├── css/
│   └── style.css       # כל העיצוב (משתני צבע, טיפוגרפיה, אנימציות)
├── js/
│   └── script.js       # אנימציות גלילה + תפריט מובייל
└── images/
    ├── az.jpg           # תמונת "אז"
    └── hayom.jpg         # תמונת "היום"
```

## איך מריצים מקומית

אין תלות בשום כלי build. אפשר פשוט לפתוח את `index.html` בדפדפן, או להריץ שרת סטטי מקומי:

```bash
python3 -m http.server 8000
# ואז לגלוש ל- http://localhost:8000
```

## איך מפרסמים (Deploy)

מכיוון שזה אתר סטטי טהור (בלי שרת/בקאנד), אפשר לפרסם בחינם ובלי צורך ב-Java/Node/כל שרת, למשל:

- **GitHub Pages** — Settings → Pages → Deploy from branch → `main` / root.
- **Netlify** / **Vercel** — גרירת התיקייה, או חיבור לריפו וזהו.

## גופנים

הגופנים (Frank Ruhl Libre, Heebo) נטענים מ-Google Fonts דרך `<link>` בתוך `index.html`. אם רוצים לוודא טעינה גם בלי אינטרנט, אפשר להוריד אותם ולשרת מקומית מתוך `/fonts`.

## הערות

- כל אלמנט עם קלאס `.reveal` מוסתר (`opacity:0`) ומופיע בגלילה. יש `<noscript>` fallback שמראה הכול מיד אם JavaScript לא רץ.
- טופס יצירת הקשר כרגע `mailto:` — אם בעתיד רוצים טופס אמיתי שמגיע לאימייל/CRM, זה כבר דורש שירות צד-שלישי (Formspree/Netlify Forms) או בקאנד קטן — לא Java, ברוב המקרים Node.js קטן מספיק לגמרי.
