# בדרך. — אתר + בדיקת התאמה

אתר סטטי טהור (HTML/CSS/JS פשוטים, בלי framework ובלי build step) לתהליך הליווי האישי "בדרך.". עברית מלאה, RTL.

## המסע של המשתמש

```
סריקת QR
   ↓
דף הבית — מסך קבלת פנים קצר (תמונה + חתימה), ואז האתר עצמו
   ↓
בדיקת התאמה קצרה (/fit) — 6 שאלות + מסך רפלקציה אחד
   ↓
תוצאה מיידית (בלי מסך "מעבד...")
   ↓
המשך לאתר, או וואטסאפ/קלנדלי ישירות
```

השינויים בפועל בכל שלב, כולל הנימוקים, מתועדים ב-**`DECISIONS.md`** — זה יומן ההחלטות המלא של הפרויקט, שווה לקרוא לפני שמשנים משהו.

## חשוב לדעת לפני שמריצים מקומית

הקבצים ב-`fit/` טוענים CSS/JS דרך **נתיבים מוחלטים** (`/css/style.css`, `/fit/fit.css` וכו'), כדי שזה יעבוד נכון בפריסה האמיתית. המשמעות: **פתיחת `fit/index.html` ישירות כקובץ בדפדפן (`file://`) לא תעבוד** — ה-CSS וה-JS פשוט לא ייטענו. צריך שרת מקומי:

```bash
python3 -m http.server 8000
# ואז לגלוש ל- http://localhost:8000  (דף הבית)
# ול-        http://localhost:8000/fit/  (בדיקת ההתאמה)
```

`index.html` הראשי (דף הבית) כן טוען עם נתיבים יחסיים, ולכן אפשר לפתוח אותו ישירות כקובץ — אבל עדיף להתרגל לשרת המקומי כדי לבדוק את שני הדפים באותה שיטה.

## איך מפרסמים (Deploy)

האתר רץ כרגע על **Vercel**, מחובר לריפו הזה — כל push ל-`main` אמור להפעיל deploy אוטומטי. אין תלות בשום build tool.

## הברקוד (QR)

ה-QR ב-`qr/baderech-fit-qr.png`/`.svg` מקודד את `https://baderech.vercel.app/?src=qr-card` — **מפנה לדף הבית**, לא ישר לבדיקת ההתאמה. אם משנים את זה בעתיד, חשוב לבדוק אם כרטיסי ההדפסה (`card-a6-*`, `card-business-*`) כבר הודפסו וחולקו לפני שמעדכנים את הקובץ בפועל.

## גופנים

Frank Ruhl Libre (serif) ו-Heebo (sans) נטענים מ-Google Fonts דרך `<link>` בראש כל דף.

## הערות טכניות

- כל אלמנט עם קלאס `.reveal` / `.reveal-pop` מוסתר בהתחלה ומופיע בגלילה (IntersectionObserver ב-`js/script.js`). יש `<noscript>` fallback שמראה הכול מיד אם JavaScript לא רץ.
- מסך קבלת הפנים (`#greeting`) מופיע פעם אחת בלבד לכל session (נשמר ב-`sessionStorage`).
- תשובות בדיקת ההתאמה נשמרות זמנית ב-`sessionStorage` בזמן המילוי, ונמחקות ברגע שמוצגת התוצאה.
- כשמישהו מסיים את בדיקת ההתאמה, סיכום התשובות מועבר פעם אחת ל-`sessionStorage` כדי שגם כפתורי הוואטסאפ הרגילים בדף הבית יישאו אותו (לא רק הכפתור בתוך הפאנל עצמו) — הלוגיקה נמצאת גם ב-`fit/fit.js` וגם ב-`js/script.js`.
- אין טופס יצירת קשר באתר כרגע — הפנייה היא תמיד דרך קישורי WhatsApp/Calendly ישירים.
